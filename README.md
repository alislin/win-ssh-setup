# win-ssh-setup

Windows SSH 免密登录一键配置工具：两台电脑各运行一次脚本，自动完成 SSH 密钥认证配置（含管理员账户 / 微软在线账户的已知问题适配），全程只需在客户端输入一个配对码（局域网 6 位一次性码；异地场景可用 8 位持久码）。

## 环境要求

- 两台 Windows 10 / 11 电脑，处于同一局域网（本机自连模式只需一台）
- Node.js ≥ 18 —— 双击 `run.cmd` 时未安装会自动通过 winget 安装 LTS 版
- 服务器端需要管理员权限（脚本自动弹出 UAC）
- 服务器端未安装 OpenSSH Server 时自动安装（winget 优先，失败回退系统可选功能）

## 快速开始

1. 两台电脑分别双击 `run.cmd`（未装 Node.js 会自动通过 winget 安装 LTS）
2. 被连接的一台选 `[1] 服务器端`（自动 UAC 提权、自动安装 OpenSSH Server），记下屏幕上的配对码
3. 发起连接的一台选 `[2] 客户端`，选择发现的服务器（或手动输 IP），输入配对码
4. 脚本自动完成：生成密钥 → 部署公钥 → 修复 ACL → 适配 sshd_config → 重启 sshd → **配置体检（无连接的 11 项检查）** → 旧 key 残留清理询问 → 可选实测验证
5. 日常管理选 `[4] 密钥管理`：区分客户端/服务端密钥，支持体检、删除、清空、备份、重新生成客户端密钥
6. 给手机/平板发钥匙选 `[5] 密钥颁发`：服务端生成专用密钥并部署，私钥导出到桌面自行导入，详见 docs/使用说明.md 的「密钥颁发」章节

详见 [docs/使用说明.md](docs/使用说明.md)，设计背景与手工流程见 [docs/手动操作流程.md](docs/手动操作流程.md)，技术方案见 [docs/技术方案.md](docs/技术方案.md)。

## 运行模式

```
 [1] 服务器端  —— 本机作为被连接的 SSH 服务器（需要管理员）
 [2] 客户端    —— 本机发起连接，把本机公钥部署到对方
 [3] 本机自连  —— 生成密钥并部署到本机（ssh localhost）
 [4] 密钥管理  —— 客户端/服务端密钥查看、体检、删除、清空、备份
 [5] 密钥颁发  —— 服务端为手机等设备生成专用密钥并部署，导出私钥自行导入
```

## 特性

- 零第三方依赖：仅使用 Node.js 内置模块
- 两机对联：公钥通过网络直接传输，无需复制粘贴
- 三层验证：部署 → 配置体检（无连接，11 项）→ 可选 BatchMode 实测
- 持久配对码：服务器端按 `p` 激活 8 位不轮换配对码，适合出差/异地连接；可客户端远程销毁或服务器端按 `d` 销毁，进程退出自动失效
- 防爆破锁定：配对码连续错 5 次锁定 30 分钟，临时码/持久码均受保护
- 密钥管理：区分客户端/服务端密钥，授权公钥按〔已颁发→标签〕〔本机客户端〕〔外部配对〕标注防误删，删除/清空/备份/重新生成，全程自动备份
- 密钥颁发：服务端为手机等设备生成专用密钥（ed25519，可选口令）并即时部署，私钥导出到桌面自行导入，交付确认后服务器零残留；注释 `#issued:标签` 便于辨认与吊销
- 换 key 闭环：重新配对自动检测同主机旧公钥并询问清理，永不误删新 key
- 幂等：重复运行不产生重复公钥、不重复备份
- 安全：sshd_config 先备份，`sshd -t` 校验失败自动回滚；授权文件 ACL 用 SID 收紧，不受系统语言影响

## 网络与端口

- TCP **22887**：配对通道（部署、体检回传、旧 key 清理、持久码销毁共用），服务器端自动添加临时防火墙规则，退出自动删除
- UDP **22888**：局域网发现信标（每 2 秒广播一次）
- **临时配对码**（默认）：6 位数字，一次性使用，配对成功后自动轮换；未使用时每 5 分钟轮换（间隔可在 `src/config.js` 调整）
- **持久配对码**（服务器端等待界面按 `p` 手动激活）：8 位数字，不轮换、可重复使用，直至手动销毁（服务器端按 `d`，或客户端配对后远程销毁）或进程退出；异地连接需自行保证 22887 端口可达（路由器端口映射或 VPN）
- **防爆破锁定**：配对码连续输错 5 次锁定 30 分钟（`src/config.js` 可调），锁定期间所有配对请求一律拒绝

## 常见问题（节选）

- **客户端搜不到服务器**：多为不同网段、路由器 AP 隔离或防火墙拦截广播，客户端选 `[m]` 手动输入服务器 IP 即可。
- **VPN / 跨网段场景**：UDP 广播跨不过隧道属预期行为，直接手输 IP（配对走 TCP 通道）。
- **体检有 FAIL**：按修复建议处理，多数可在 `[4] 密钥管理` 中 `[c]` 体检后一键修复。
- **winget 安装失败**：自动回退系统可选功能安装；都失败时按提示手动安装后再运行。
- **中文乱码**：建议使用 Windows Terminal。

更多见 [docs/使用说明.md](docs/使用说明.md) 的「常见问题」章节。

## 回滚与卸载

- `sshd_config`：用备份 `C:\ProgramData\ssh\sshd_config.bak.<时间戳>` 覆盖回去，再 `Restart-Service sshd`
- 公钥：所有删除/清空操作前均有 `.bak.<时间戳>` 自动备份，可在 `[4] 密钥管理` 中回退
- 卸载 OpenSSH Server：`winget uninstall Microsoft.OpenSSH.Preview`
